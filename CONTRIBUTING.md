# Contributing to sysmon
## Pull Request Workflow
1. Fork the repository: `git fork https://github.com/username/sysmon.git`
2. Create a new branch: `git checkout -b feature/branch-name`
3. Make changes and commit: `git commit -m "Detailed commit message"`
4. Push changes: `git push origin feature/branch-name`
5. Submit a pull request
## Commit Standards
* Use descriptive commit messages
* Follow the GitHub commit message guidelines
## Code Style Rules
* Use PEP 8 for Python code
* Use consistent indentation and spacing
